# 日常记账

记录日常收入与支出，为存款目标一点点积累。

[![打开日常记账](.github/open-app.svg)](https://fxctx233.github.io/-/)

> 首次使用须先完成 GitHub Pages 发布。若按钮打开为 404，请在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，再到 **Actions → Publish Daily Ledger → Run workflow** 运行发布；等待部署成功后再打开。

## 直接使用

点击上方按钮打开网页版，无需下载项目、Node.js 或启动 CMD。也可以将网址收藏到浏览器书签。

- 支出和收入大圆形入口，彩色分类按钮，自动记录日期与时间。
- 可选备注、账目修改和删除、年月日统计。
- 特殊补记选项：指定过去的日期，时间可留空，自动归入对应统计。
- 存款目标、已存金额和剩余金额。
- 分期存款计算器：按每月预算或期数生成安排，逐期勾选完成、取消勾选；也可手动完成或重新开启整个计划。
- 五种配色，本地保存偏好。
- JSON 完整备份与恢复。
- 支付宝／微信账单本地导入、自动分类和重复识别，批量改类／删除、分类与日期时间金额筛选及排序。
- 当前资金总额与收支联动，支持手动校准；记账后可返回、修改和撤销。

## 你的账目在哪里？

网站公开，但每个人的账目只保存在自己当前浏览器的本地存储中，不提交到 GitHub，也不与其他访问者共享。GitHub 负责提供网页文件，可能记录一般网站访问日志。

**网页版与 localhost 本地版不是同一个存储位置。** 第一次使用网页版，需要在本地版“分类与备份”中导出 JSON，再到网页版导入。更换浏览器、设备或清理浏览器数据前也要备份。不同设备不会自动同步。

同一 GitHub Pages 域名下的其他项目可能共享浏览器存储来源，不要在该域名托管不可信代码。备份文件是明文，请妥善保管，不要上传到公开仓库。

首次加载网页需要网络；当前版本不保证断网后重新打开可用。存款提醒仅在页面内显示，不提供关闭页面后的系统通知。

## 安卓手机版

提供 Android 8.0 及以上的竖屏离线测试版：顶部圆形记账入口、底部导航，内置 SQLite 和系统文件备份。当前 0.3.0，包含历史补记、分期存款计划、资金总额和手机支付账单导入审核。

在 [Build Android APK](https://github.com/fxctx233/-/actions/workflows/android.yml) 中打开最近成功的构建，下载 `daily-ledger-android-debug` 产物并解压取得 APK（下载 Actions 产物可能需要登录 GitHub）。测试包不是正式商店发行版；安装和升级前请查看 [安卓说明](android/README.md)。网页版与安卓数据需通过导入导出转移，不自动同步。

## 自动更新

GitHub Pages 启用后，每次向 main 推送更新都会自动测试、构建并发布。只发布 `pc-web/dist-pages` 中的网页文件，不发布账目备份或整个源码目录。
