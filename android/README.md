# 日常记账 Android 竖屏试用版

当前版本：0.3.0，Android 8.0 及以上。

## 本次更新

- 竖屏布局：顶部圆形支出／收入入口、底部四个导航、四列彩色分类。
- 首页当前资金总额可设置、增加或减少；收支、编辑、删除、导入和撤销同步调整余额。
- 账单卡片左侧勾选，支持批量改类和删除；类型横向滚动，日期／时间／金额筛选按需展开，排序单独保留。
- 记账完成后可返回、手动修改或撤销本笔。
- 支付宝 CSV、微信 XLSX／CSV 导入，自动分类、退款收入、精确交易指纹去重及时间相同的可疑订单提示；审核在手机上显示为竖向卡片。
- 历史日期补记、分期存款计算器、逐期完成／取消、五种配色及 JSON 完整备份。

## 手机导入账单

1. 将支付平台导出的账单保存到手机“下载”目录，邮件中的 ZIP 先解压。
2. 在“账单明细 → 导入支付账单 → 选择账单文件”打开安卓文件选择器。支持 CSV / XLSX，单份不超过 10 MB，一次最多 8 份。
3. 查看自动分类和可疑订单，可切换支付宝／微信来源并批量调整。
4. 勾选使用自动分类结果，核对汇总，再确认保存。选择文件本身不会立即记账。
5. 导入重叠时间段会追加新交易、跳过已入账的相同交易，不覆盖手动修改。不同订单时间完全相同时提示核对。

## 离线与数据

完整网页随 APK 打包，首次启动也不依赖网页服务，没有 INTERNET 权限，不申请整个存储空间访问权限。请保持 Android System WebView 更新。

账本、配色和操作前副本保存到应用专属 SQLite。原始账单不上传、不复制到公开仓库；应用不启用系统云备份。PC、网页版与安卓各自独立，通过完整 JSON 备份转移。新版保留余额、商家规则、来源指纹和原交易秒数；不要用旧版安卓往返保存新版备份。

操作前副本仅保留各类操作最近一次，不能代替定期导出。备份是明文，请私下保管。卸载、清除应用数据或更换安装包前先导出并核对备份。

仅支持应用内存款进度提醒，尚无关闭应用后的定时通知。普通存取暂不保存逐笔历史。

## 安装与升级

这是 debug 签名的测试安装包，不是正式应用商店版本。GitHub Actions 每次全新构建可能使用不同测试签名；如提示签名冲突，先在旧版导出完整 JSON，并确认文件可用，再卸载旧版、安装新版和恢复。不要直接卸载有账目的旧版。

没有连接安卓真机时，网页竖屏验证和 APK 编译检查不等于真机验收。请在手机重点测试文件选择、键盘遮挡、导入后重启保存、JSON 导出恢复和系统返回键。

## 构建

要求 JDK 17、Gradle 8.7、Android SDK platform 35、build-tools 34.0.0。

1. 在 pc-web 运行 npm ci、npm run build:pages。
2. 在根目录运行 node android/prepare-assets.mjs。
3. 设置 ANDROID_HOME，或在 android/local.properties 设置 sdk.dir。
4. 运行 gradle -p android assembleDebug lintDebug。

APK：android/app/build/outputs/apk/debug/app-debug.apk。

也可在 GitHub Actions → Build Android APK 下载最近成功构建的 daily-ledger-android-debug 产物，默认保留 30 天。源码长期保留，私有签名密钥不得提交。
