# 日常记账 PC 网页预览

双击项目根目录的“启动日常记账.cmd”，在可见窗口中启动本地服务。看到 http://localhost:5173/ 后，双击“日常记账网页.url”打开浏览器。使用期间保持服务窗口开启。

“日常记账网页.url”需要服务已经运行。新启动入口直接运行 Node.js，不使用 PowerShell、不隐藏进程、不修改杀毒软件或系统安全设置。如果提示端口 5173 已占用，先尝试打开网页，不要重复启动。原“打开日常记账.cmd”后台入口已停用，不建议从隔离区恢复。若仍被拦截，请保留防护并提供威胁名称和被拦截文件路径以排查。

界面右上方的“界面配色”可选择绿、蓝、紫、粉、暖杏五种主题，设置保存在当前浏览器，不修改账目。

需要本机已安装 Node.js，开发依赖已安装。关闭启动窗口会停止网页服务。重启时使用相同的 localhost 地址及 5173 端口，以继续访问当前浏览器的账本。

## 可以试用
- 顶部圆形收入/支出入口；填写金额、点击彩色圆形分类、点击圆形确认完成记录。新增自动使用本机当天日期，修改历史账目保留原日期和原备注。
- 按年、月、日统计、查看趋势及分类汇总，搜索和筛选账单。
- 创建及编辑存款目标、存入或取出金额、查看剩余金额及每月建议。
- 收入/支出中的“特殊选项”支持补记过去的日期及可选时间。
- 存款计划中的分期计算器支持按每月金额或月数计算；逐期完成会计入已存金额，取消勾选撤回；整体完成标记不改变金额。
- 独立示例模式，修改示例不会写入真实账本。
- JSON 完整导出、校验导入、确认替换，自动保留一个恢复前副本。

## 当前限制
- 数据存于当前浏览器的 localStorage，尚不是 SQLite 独立数据库。清理浏览器数据、无痕模式或切换浏览器可能导致数据丢失；请定期导出备份。
- 没有云同步、上传或账号。备份为明文，不含加密。
- 页面内显示存款提醒，关闭网页后不会通知。
- 分期安排与勾选状态会保存并导出；普通存入/取出暂不保存逐笔历史。不能把已存金额改成低于勾选分期的总额，需要先取消相应期次。
- 分类支持新增，暂不支持重命名及删除。
- 网页代码依赖的开发工具体积较大，与实际账目占用空间不同；不代表未来 PC 安装包大小。
- 这次未发布外网，也没有生成 Windows 安装包或安卓 APK。

开发验证：npm run build；npx tsc --noEmit；node --experimental-strip-types --test lib/ledger.test.ts。
